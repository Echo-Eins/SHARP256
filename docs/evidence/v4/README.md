# Версия 4 в NAT-лаборатории

Прогоны `scripts/natlab/natlab.py` после того, как получатели стали
печатать свой ID в форме `sh4-`: лаборатория берёт ID из их вывода, так
что каждая передача здесь — версия 4 целиком (гибридное рукопожатие во
фрагментах, HELLO после него) через настоящие NAT ядра Linux, ретранслятор,
карточки, DHT, введённые адреса, локальную сеть и NAT оператора.

Итог тот же, что у версии 3 в `docs/evidence/nat/` и
`docs/evidence/amplification/`, пара за парой: 36 из 36 через ретранслятор
(32 напрямую, 4 через него), 32 из 36 по карточкам, через DHT и по
введённым адресам (четыре пары двух симметричных NAT без ретранслятора не
соединяются и не должны), 18 из 18 через DHT по IPv6. Рукопожатие версии 4 —
около 1,4 КБ во фрагментах вместо ~200 Б — ни одного пути не отняло.

`natlab-dhtplant.log` — узел DHT, подбрасывающий адрес: на версии 4 адрес
из DHT до поручительства двух узлов (или ответного пробивающего пакета) не
получает ни распыления, ни инициаций — 576 Б за трудную встречу, 828 Б за
минуту поиска никого (без этого ограничения версия 4 давала 4,5 КБ и 27 КБ:
одна инициация весит полтора килобайта).

Шапка каждого журнала называет сборку; прогоны без DHT шли на сборке до
этого ограничения, которое касается только путей DHT.
